# Job_Future

An interactive chart page showing published forecasts of jobs created and lost as AI and automation are adopted.

Open `index.html` in a browser. It's one self-contained file with no dependencies or build step.

## What's on the page

1. **Forecasts of jobs created vs. displaced, by target year.** WEF Future of Jobs 2020, 2023 and 2025, the WEF 2025 AI-only share, and McKinsey 2017, with a toggle to zoom in on the WEF numbers.
2. **How much work is done by people vs. technology.** WEF 2025's expected shift in task shares, now vs. 2030.
3. **US jobs the BLS expects AI to push up or down, 2024–2034.** BLS Employment Projections for the occupations it names as affected by AI.
4. **Job types with the biggest worldwide gains and losses, 2025–2030.** From WEF 2025.

Each chart has hover and keyboard tooltips, a table view where it applies, and supports dark mode.

## Sources

- World Economic Forum, [Future of Jobs Report 2025](https://reports.weforum.org/docs/WEF_Future_of_Jobs_Report_2025.pdf)
- World Economic Forum, [Future of Jobs Report 2023](https://www.weforum.org/press/2023/04/future-of-jobs-report-2023-up-to-a-quarter-of-jobs-expected-to-change-in-next-five-years/)
- World Economic Forum, [Future of Jobs Report 2020](https://www.weforum.org/publications/the-future-of-jobs-report-2020/in-full/executive-summary/)
- McKinsey Global Institute, [Jobs lost, jobs gained](https://www.mckinsey.com/featured-insights/future-of-work/jobs-lost-jobs-gained-what-the-future-of-work-will-mean-for-jobs-skills-and-wages) (2017)
- US Bureau of Labor Statistics, [Artificial intelligence, information technology, and employment, 2024–34](https://www.bls.gov/opub/ted/2026/artificial-intelligence-information-technology-and-employment-2024-34.htm) (2026)
- Goldman Sachs, [How will AI affect the US labor market?](https://www.goldmansachs.com/insights/articles/how-will-ai-affect-the-us-labor-market)

The forecasts use different methods and scopes, so they aren't directly comparable. The page explains the differences.
